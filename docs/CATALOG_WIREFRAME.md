# Wireframe katalog publik · T07

Pada ponsel selebar 360 px, pelanggan bisa membuka daftar menu langsung dari tombol di bagian atas.

```text
┌──────────────────────────┐
│ DJAJAN                   │
├──────────────────────────┤
│ Mac & Cheese             │
│ [Lihat menu]             │
├──────────────────────────┤
│ Daftar menu              │
│ [Classic]   [Royale]     │
│ [Signature] [Deluxe]     │
│ Menu lain menyusul       │
└──────────────────────────┘
```

Pada desktop, empat kartu tampil dalam satu baris. Setiap kartu menampilkan foto (sementara placeholder warna brand berisi nama menu), nama, deskripsi singkat, dan harga. Chip filter kategori hanya muncul bila ada lebih dari satu kategori; saat ini semua menu berkategori Mac & Cheese.
