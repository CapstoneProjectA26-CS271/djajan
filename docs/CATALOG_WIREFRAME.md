# Wireframe katalog publik · T07

Pada ponsel selebar 360 px, pelanggan bisa membuka daftar menu langsung dari tombol di bagian atas.

```text
┌──────────────────────────┐
│ D’JAJAN                  │
├──────────────────────────┤
│ Mac n’ Cheese.           │
│ [Lihat menu]             │
├──────────────────────────┤
│ Daftar menu              │
│ [Semua] [Mac n’ Cheese]  │
│ [Classic]   [Royale]     │
│ [Signature] [Deluxe]     │
└──────────────────────────┘
```

Pada desktop, empat kartu tampil dalam satu baris. Setiap kartu menampilkan nama, ukuran, dan harga. Slot foto dapat ditambahkan setelah aset produk tersedia.
